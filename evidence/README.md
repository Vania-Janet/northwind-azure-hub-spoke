# Evidencias

Carpeta para capturas y comprobaciones del MVP.

Para Fase 1 se usaran estas rutas:

- `01-resource-group/`: captura del Resource Group y tags.
- `02-hub-vnet/`: captura de Hub VNet y subnets.
- `03-spoke-vnet/`: captura de Spoke Operaciones y subnets.
- `04-peering/`: captura de peering Hub -> Spoke y Spoke -> Hub.

Estas evidencias se agregan despues de ejecutar `terraform apply` y validar los recursos en Azure Portal o Azure CLI.
